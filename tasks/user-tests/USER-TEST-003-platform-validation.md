# USER-TEST-003 — Platform Validation

## Amaç

Windows ve macOS platform adapter davranislarini kullanici seviyesinde dogrulamak.

## Platform

Windows ve macOS

## Adimlar

1. Uygulamayi Windows'ta ac.
2. Start / Stop / F8 / CPS / sayac / sure akisini dogrula.
3. Uygulamayi macOS'ta ac.
4. Start / Stop / CPS / sayac / sure akisini dogrula.
5. macOS izin eksikligi varsa mesajin anlasilir oldugunu dogrula.

## Beklenen Sonuc

- Windows MVP akisi release adayi olarak calisir.
- macOS mouse backend calisir veya izin eksikligini net mesajla bildirir.
- Platform adapter hatalari sessiz kalmaz.

## Durum

Bekliyor.
